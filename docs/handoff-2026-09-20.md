## Two open findings, recorded rather than encoded

Dwarven Steel and Minotaur Hide run **3.5×** and **11.6×** over prediction while
the **1,000 GP Bar runs a third short** — 67 bars across 499 packs. Surplus
(+128) and shortfall (−139) balance, so the total is right and only the
allocation is wrong: the signature of **substitution, not addition**.

The obvious explanation — that Commons are converted too — is **rejected twice**:
the two goods imply 6.7 and 12.0 Commons per pack, which one parameter cannot be,
and either value overshoots the total by 7.3% where Rare and Uncommon alone land
at 0.2%.

No company statement exists either way and nobody tracks the GP bar shortfall.
**Re-test in 2027.** This is the first thing the project has found that the
community does not already know.

## The thing that will silently go wrong

**`token_catalog_2027.csv` has no `Treasure Chest Only` tokens**, because the
season's chase sets and treasure-exclusive Rares are not public until after
January 2027. 2026 has **68** of them — 22 Rare and 46 `Quest`.

So the chase groups will exist with **zero members** until then, and any chase
rate computed before that date is measuring an empty set and will look like a
confident zero rather than an error.

```
node scripts/fetch_catalog.mjs 2027
```

Re-run that after January 2027, then re-run the checks. It is idempotent.

## Traps, all of which cost time once

- **tokendb has no token REST route.** The custom post type is not exposed, and
  `/wp-json/wp/v2/posts` returns zero. The interface is FacetWP's
  `/wp-json/facetwp/v1/refresh`, which is public, takes
  `template: 'token_search_results'`, and returns rendered listing HTML plus a
  pager. URL query params (`?_pub_year=2027`) do **not** filter it.
- **FacetWP multi-select is OR, not AND.** Deriving per-good, per-rarity counts
  by inclusion–exclusion over the facet *looks* like it works and produced **four
  phantom divergences** from the owner's table. No token carries two goods; the
  per-token pull agrees everywhere. **Always count tokens, never intersect
  aggregates** — V9 exists because of this.
- **Token names contain commas** (`1,000 GP Gold Bar`) and apostrophes. Never
  split on `,`; `check_conversion.mjs` carries a real quoted-CSV parser for this
  reason, and the fetcher decodes `&#039;` on the way in.
- **The three workbooks are gitignored and their paths are in this project's
  memory directory**, not here, because this repository is public. Aggregates
  needed for the checks are committed in `scripts/fixtures/` instead. Say which
  copy of the 2024 workbook a measurement used.
- **`py`, not `python`** on this box. `openpyxl` 3.1.5 is installed. Load with
  `data_only=True`. The 2026 sheet layout gotchas are in
  `scripts/fixtures/README.md`.
- **CSVs are pinned to LF** by `.gitattributes`. Markdown and `.mjs` are not, and
  git will warn about CRLF on those; that is expected.
